# ADEDEJI TRAPS LABORATORY · Student tool kit

Interactive teaching toolkit for the Ecomicrobiology Lab (TRAPS: Tracking pathogens in aquatic systems), University of the District of Columbia.

The whole site is one self-contained file, `index.html`, with images embedded and no build step. Modules: Phenotypic Identifier, Organism Reference, PCR Assistant, Nanopore Sequencing, and SOPs.

Entries are stored only in each student's own browser. Phenotypic evaluation is for teaching only. Further molecular analysis is necessary for accurate identification.
