Scoring, assay coverage, and sources

Further molecular analysis is necessary for more accurate identification.

Phenotypic match = 100 × matches ÷ (comparable results + 3). A comparable result has an explicit positive or negative reference call. Conflicts lower support. An unentered, variable, weak, or undocumented result contributes no evidence. Agreement divides matches by comparable results alone. The scores are heuristic and have no probability calibration.

Sample type is recorded for context. The candidate details identify which entered tests have supporting reference data, including whether an assay has any coverage in this panel.

Phenotype data · The panel draws on Bergey’s Manual of Systematic Bacteriology, Vol. 4, plus selected reference-strain results from peer-reviewed species descriptions and DSMZ BacDive. Updated or disputed reactions have source links in the evidence tables. The score excludes disputed results. Use the listed assay and record strain-specific findings with care.

Current reference · Bergey’s Manual of Systematics of Archaea and Bacteria is the online successor. Species names in this panel were checked in LPSN on November 22, 2026.

PCR workflow and pre-lab checklist

Use a synthetic teaching template or instructor-provided DNA from an approved nonpathogenic reference, such as Escherichia coli K-12.

  1. ▤

    Complete the worksheet

    Before starting, record the run ID, reaction volume, sample IDs, and required controls. Check the approved assay sheet for the expected product.

  2. ∑

    Calculate the shared mix

    Count every tube, including controls. Add an allowance for pipetting loss and check that shared mix plus the reserved addition equals the final tube volume.

  3. ⇥

    Label and check transfers

    Label tube sides so IDs remain visible. Use a pipette rated for the volume, use fresh tips between transfers, and check that liquid was drawn up and dispensed.

  4. ±

    Set up controls

    Keep template and control additions separate from the shared mix. Set up and cap the no-template control before handling sample DNA.

  5. ↻

    Run the thermocycler

    Confirm the instructor-approved program and reaction volume. Record the run ID so the tube map and resulting data stay together.

  6. ✓

    Review controls first

    Evaluate products in the designated post-PCR area. A reaction may look unchanged after cycling. Use the expected product and controls to interpret the result.

Concentrations

Check the reagent label first. Copy the stock concentration and unit from the reagent label or product sheet. Enter the desired final concentration from your approved assay sheet.

Typical final values for an individual-reagent PCR mix (editable teaching defaults). MgCl₂ 1.5 mM, dNTPs 0.2 mM each, PCR buffer 1×, forward and reverse primers 250 nM each, and Taq DNA polymerase 2.5 U per reaction. Change any value or unit to match your approved assay sheet.

Why might my values differ?

Check whether the primer pair, polymerase, or mix formulation changed. Use the current assay sheet for final values and the reagent label for stocks. Check whether the buffer or MasterMix already contains MgCl₂ or dNTPs before adding them as separate components. For Taq, check whether the assay lists total units per reaction or units per microliter.

How volumes are calculated

Dilution factor = stock ÷ final after converting to matching units. Volume per tube = reaction volume ÷ dilution factor. Batch volumes include the selected pipetting allowance.

Common contamination sources and controls

Common sources include contaminated reagents, carryover from post-PCR products, and transfer between samples.

Keep reagent setup, template handling, and post-PCR products in their assigned areas. Use clean gloves, dedicated pipettes, and fresh filter tips.

Sequencing workflow

Use instructor-approved nonpathogenic reference material or supplied reads. Use the course SOP and matching kit guide for wet-lab procedures.

  1. ▤

    Plan and label

    Record sample IDs, controls, whether you have an isolate or a mixture, and whether the data represent genomic DNA or a 16S amplicon.

    Checkpoint · Match IDs to the sample sheet.

  2. ∿

    Prepare and check DNA

    For genomic libraries, HMW extraction aims to preserve long DNA fragments. Handle your approved material according to the course SOP and check concentration, purity, and size against kit criteria.

    Checkpoint · Record yield and integrity before starting the library.

  3. ⊕

    Prepare the library

    Use a compatible library kit. Know which stage attaches barcodes, when samples are pooled, and which adapters enable sequencing.

    Checkpoint · Confirm barcode assignments and expected library input.

  4. ▦

    Check and load the flow cell

    Match the flow cell to the kit and check pore availability in MinKNOW. Have the instructor verify the flow cell and supervise priming and loading.

    Checkpoint · Log the flow-cell ID and pore check.

  5. ▷

    Run MinKNOW

    Verify the device, kit, sample sheet, output settings, and available storage. Monitor yield, read quality, and unexpected barcode patterns.

    Checkpoint · Save the run summary and raw POD5 when available.

  6. A

    Basecall and demultiplex

    Use MinKNOW basecalling or post-run Dorado with a model compatible with the run chemistry. Assign reads to the matching barcodes and retain per-sample reads.

    Checkpoint · Record model, version, and FASTQ or BAM output.

  7. ◫

    Review read quality

    Compare read count, length and quality distributions, and unclassified barcodes. Check negative controls and unexpected reads before drawing conclusions.

    Checkpoint · Document accepted reads and exclusion criteria.

  8. ⌕

    Identify and verify

    Choose a workflow suited to the dataset. Record reference database version, reads supporting the call, competing matches, and the narrowest rank justified by the evidence.

    Checkpoint · Report unresolved calls at genus or a higher supported rank.
